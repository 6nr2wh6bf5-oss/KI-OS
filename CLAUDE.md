## Arbeitsregeln
1. **Vor der Arbeit** `git pull`, **nach der Arbeit** `git add -A && git commit && git push`.
2. Sprache: Deutsch (Schweiz), kein «ß», Anführungszeichen «…».
3. Stil: rational, klar strukturiert, Ergebnis zuerst. Tabellen und nummerierte Listen statt Fliesstext, wo sinnvoll.
4. Vorschriften: Jede Aussage zu Brandschutzvorschriften mit Fundstelle (z.B. «VKF-BSR 15-15, Ziff. 3.4.2»). Massgebend ist der Originaltext der VKF bzw. die Beurteilung der Brandschutzbehörde; das immer klarstellen, wenn eine Auslegung nötig ist.
5. Unsicherheit offen benennen. Nichts erfinden; fehlende Information als offene Frage aufführen.
6. Datenschutz (revDSG): Keine personen- oder objektbezogenen Kundendaten (Namen, Adressen, Pläne, Eigentümer) in dieses Repository. Projekte unter `20_Projekte` nur pseudonymisiert (z.B. «Projekt A-2026-03»).
