# Mail-Entwurf

## Ablauf
1. Stil aus `00_Profil/profil.md` lesen.
2. Struktur: Anrede, Kernaussage im ersten Satz, Begründung/Details (bei Bedarf nummeriert), nächste Schritte, Gruss.
3. Fachaussagen mit Fundstelle; keine verbindlichen Zusagen ohne Rückfrage.
4. Nur als **Entwurf** liefern bzw. speichern, nie selbst senden.
5. Ist ein Mail-Connector (Microsoft 365 / Google) verbunden: Entwurf direkt im Postfach als Draft ablegen.
